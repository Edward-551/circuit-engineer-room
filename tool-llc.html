LLC Resonant Converter Design

LLC設計ツール

入力電圧・出力電圧範囲・出力電力から、Vinmax基準の目標巻数比、frH/frL比からのK、必要最大ゲイン、推奨Q、Lr/Cr/Lmを自動計算します。 巻線はAL値から一次/二次巻数を自動決定する流れを標準にし、任意巻数での検証もできます。

設計思想： K/Qを直接入力するのではなく、仕様 → 巻数比 → 必要ゲイン → Q選定 → 共振部品 → 実部品検証の流れで進めます。FHAベースの初期設計用です。

入力条件

STEP1：入力電圧・出力仕様

目標巻数比は Vinmax・Voutmin 基準で算出： n ≈ Vinmax / {2(Voutmin + Vf)}。標準ではAL値とLm推奨値からNp/Nsを整数で決定します。

※ ハーフブリッジLLC、センタータップ二次の片側巻線基準の初期設計式です。

STEP2：周波数条件

K = Lm/Lr = (frH/frL)2 - 1、frL = frH / (frH/frL)

STEP3：Q選定・共振部品

Rac,p = n² × 8Rout/π²、Z0 = Q × Rac,p、Lr = Z0/(2πfrH)、Cr = 1/{(2πfrH)²Lr}

STEP4：実部品値で検証

実値入力後、frH/frL/K/Q/特性インピーダンスを再計算します。

STEP5：電流・ZVS目安

Im,pk ≈ Vinmax / (8Lm fchk)、Iload,pri ≈ Pin / Vin基本波rms、Ir ≈ √(Iload² + Im,rms²)

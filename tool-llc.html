LLC Resonant Converter Design

LLC設計ツール

出力仕様と設計条件から、巻数比、反射負荷、共振部品 Lr / Cr、励磁インダクタンス Lm を順番に導出します。 最後にゲイン-周波数特性を確認し、設計定数をCSVで保存できます。

使い方： まずSTEP1〜STEP8で定数を決め、STEP9〜STEP10でゲイン特性、STEP11で任意周波数の励磁電流とZVS関連エネルギーを確認します。FHAベースの初期設計向けです。

入力条件

STEP1：出力仕様

Iout = Pout / Vout,　Rout = Vout2 / Pout

STEP2：入力バス電圧

ハーフブリッジ一次基本波：V1,rms ≈ √2・Vbus / π

STEP3：巻数比の導出

ncalc = Np / Ns ≈ Vbus,nom / {2・Mfr・(Vout + Vf)}

Np,calc = ncalc × Ns → 切り上げ/切り下げ/四捨五入 → nuse = Np,use / Ns

※ センタータップ時は片側二次巻線基準の概算。実際の巻線構成に合わせてNsを入れてください。

STEP4：共振周波数とインダクタンス比

fr = 1 / {2π√(LrCr)},　k = Lm / Lr

STEP5：反射負荷

Rac = 8Rout / π2,　Rac,p = n2Rac

FHAで二次側整流負荷を交流等価負荷に換算し、一次側へ反射します。

STEP6：Lr / Cr の導出

Qe = √(Lr/Cr) / Rac,p

Lr = QeRac,p / (2πfr),　Cr = 1 / {(2πfr)2Lr}

STEP7：Lm の導出

Lm = kLr

kを大きくすると励磁電流は減りますが、必要ゲインやZVS範囲とのバランス確認が必要です。

STEP8：実部品値での再計算

実部品値を入れると、fr、Q、kを再計算します。

STEP9：ゲイングラフ条件

Qは「任意Qリスト」が優先です。空欄なら Q開始〜Q終了をQ刻みで自動プロットします。G軸は最小/最大を空欄にすると自動スケールです。

STEP10：必要ゲイン確認

Mreq = Vbus,nom / Vbus を目安に、低入力時の昇圧余裕を確認します。

STEP11：励磁電流・ZVSエネルギー確認

Im,pk ≈ Vbus,max / (8Lmfchk)

ELm = 1/2 LmIm,pk2,　ECsw = 1/2 CswVbus,max2,　tdead,min ≈ CswVbus,max / Im,pk

軽負荷・高入力・高周波側での概算確認用です。CswはMOSFETのCossだけでなく、スイッチングノードにぶら下がる容量を含めた目安値を入れてください。

STEP12：保存

設計条件・導出値・実部品値・ゲイン確認・励磁電流/ZVSエネルギー結果をCSV出力します。グラフデータもCSVで出力できます。

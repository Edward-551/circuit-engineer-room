# 回路エンジニアの部屋

電源設計・電子回路に関するメモと計算ツールをまとめる個人サイトです。

## サイト内容

- 抵抗ネットワーク計算ツール
- 分圧計算ツール
- 抵抗の定格確認ツール
- PFC / LLC まわりの設計・評価メモ
- 部品選定で迷いやすいポイントの記録

## 目的

回路設計や評価でよく使う計算、実際にハマったこと、あとで見返したい技術メモを整理するために作っています。

まずは自分が使いやすいことを優先しつつ、同じような内容で困る人にも役立つサイトを目指しています。
